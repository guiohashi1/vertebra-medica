# Vertebra Médica

Landing page de catálogo para camas e colchões hospitalares, com visualização 3D e solicitação de orçamento pelo WhatsApp.

## Stack

- Vite + React + TypeScript
- Three.js via React Three Fiber
- Lenis (scroll suave) + GSAP ScrollTrigger

## Desenvolvimento

```bash
npm install
npm run dev
```

## Configuração

Edite o telefone em `src/config.ts` (`WHATSAPP_PHONE`, somente dígitos com DDI).
